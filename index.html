My Skills

HTML

Building the structure of websites.

What is HTML?

HTML stands for HyperText Markup Language. It creates the structure of a webpage using elements such as headings, paragraphs, images, links, lists and forms.

Example: HTML creates the content and structure you see on a website.

CSS

Designing attractive and responsive websites.

What is CSS?

CSS stands for Cascading Style Sheets. It controls how HTML elements look, including colours, fonts, spacing, backgrounds and layouts.

Example: CSS makes a webpage colourful, organized and responsive on different screen sizes.

Java

Learning programming and logical thinking.

What is Java?

Java is a general-purpose, object-oriented programming language used to build software and applications.

Example: Java helps programmers write instructions, solve problems and develop different types of applications.

Remember: Java and JavaScript are different programming languages.
